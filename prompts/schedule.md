# 蔚藍檔案 更新日程整理

把官方更新日誌整理成固定格式的 Discord「更新預告」貼文。產出是一段包在 ```markdown 程式碼區塊裡的純文字,核心是用 `┬ │ ┴` 三種字元畫出的 ASCII 時間軸。

## 重要前提

- **輸出永遠是單一 ```markdown 程式碼區塊**,方便直接複製貼到 Discord。不做成檔案、不用 artifact。
- **時間軸對齊是重點與難點**。寧可多花心力把線條對準,也不要交出歪掉的時間軸。
- 角色名、活動名沿用該伺服器的官方譯名。不確定時保留原文並向使用者標註,不要自行編譯名。
- 資料有缺口 (Discord 連結、未確認的 BOSS 英文名或譯名) 時,**留空並明確告知待補**,不用猜測填入。
- 使用者手動修正過的版本就是標準答案:比對差異、記下規則,之後照做。

## 整體結構

### 國際版

```
@通知-國際版
[國際版] 更新預告
* 維修時間：7/21(二) 10:00 ~ 13:45
* 維修補償：青輝石600個

### 劇情
7/21 追加
- ...

### 更新
7/21 追加
- ...

### 日程
`時間軸` - 事件
```

### 日版

```
@通知-日版
[日版] 維修預告
- 維修時間：7/8(三) 10:00 ~ 16:00 (UTC+8)

### 劇情
...
```

規則:
- 開頭用可讀的提及寫法 `@通知-國際版`、`@通知-日版`,不用 `<@&數字ID>`。
- 國際版標題「更新預告」、維修行用 `*`;日版標題「維修預告」、維修行用 `-`。
- **時區一律 UTC+8**。日版公告是 JST,要減 1 小時 (11:00~17:00 → 10:00~16:00),並標註 `(UTC+8)`。國際版原本就是 UTC+8,照抄、不標時區。
- **維修結束時間用實際時間**:公告若有「下午3點 → 下午1點45分」這類更新,寫更新後的 13:45。
- 補償照公告寫,有延長補償就並列:`青輝石480個 + 青輝石240個(延長維護補償)`。日版通常沒有補償行。
- 區塊之間空一行;日期分組寫「7/8 追加」(不加冒號),項目用 `-`,子項目縮排兩格。
- **篩選後沒有項目的區塊整個省略**,不留空標題 (常見只剩 `### 日程`)。

## 劇情區塊

列在 `### 劇情`,依實際開放日期分組:
- 主線新章節 (含話數,例:`主線劇情 第2部 Vol.2「奧德賽」篇 第1章「映於瞳中的水平線」前半 (01~08話)`)
- 主線語音追加 (韓語配音等)
- 短篇劇情、迷你劇情、群組劇情
- 活動常駐化,寫成 `活動「XXX」常設化`
- 第2部的劇情附屬功能 (例:FruLink)

不列:愛用品附帶的羈絆劇情、活動內的劇情 (已由活動本身代表)。

## 更新區塊的取捨 (關鍵)

判準從嚴,寧可少列。一份二十幾項的公告,過濾後常常只剩一兩條或整個省略。

**不列出** —— 例行性、與玩法關係不大:
- 新增學生、家具、家具互動 (家具 motion)、樣品屋
- 組合包、商品販售、商店例行更新與購買次數重置、商店新增商品
- 製造/家具箱新增道具
- 新增任務、稱號、實績
- 錯字、顯示錯誤、特效與細部 UI 修正
- **各種 bug 修正**,即使是機制性的
- 技能說明文字調整 (公告註明不影響效果者)
- 動作模組微調、商店販售期限顯示、賽季結束日期顯示等介面標示
- 獎勵加倍活動
- 我的辦公室特別任務 (與活動同期,不另列)

**要列出** —— 會實際影響玩家的:
- **愛用品追加** (寫法見下)
- 新募集機制:Limited Dash / PremiumDash 募集 (列出可選學生與可抽期限)
- 新手/回歸活動 (例:「夏萊正式派遣！歡迎您，老師！」)
- 標題影片 (例:7th PV)
- 總力戰、大決戰、制約解除決戰的戰鬥機制改善/變更,以及房間初始化、排名搜尋、重新開始等功能
- 戰術大賽賽季的規則變更 (地形、體力、FEVER TIME 等)
- 懸賞通緝等內容的結構改善 (新區域、學園效果重新分配、掉落率)
- 新系統與系統性變更:模擬總力戰、萬能設計圖、起始技能數、票券持有上限、AP返還、難度下修、助攻學生、相性顯示設定、家具鎖定、搜尋功能、PC版快捷鍵/手把、咖啡廳批次送禮、社團除名名單、值日生隨機等
- 第2部主線的劇情系統變更 (探索劇情、提問選項)

**不確定時**在區塊外詢問使用者,例如:模擬總力戰新增頭目、平台年齡分級等公告。

寫法範例:
```
- 愛用品追加
  - 花凛(兔女郎)、伊呂波、綾音
- PremiumDash招募
  - 可選定若藻、星野(泳裝)、彌香作為特選對象
  - 帳號建立或維護後首次登入起算28天內可以抽取
- 總力戰、大決戰新增「房間初始化」功能
  - 每張票券可使用1次，重置BOSS HP、使用部隊與幫手使用狀況
```

## 時間軸畫法

每一行格式:

```
`日期 線條欄位` - 事件描述
`     線條欄位`  。子項目
```

- 日期與線條包在一對反引號裡 (等寬才能對齊);事件描述在反引號**外**,接 ` - `。
- 子項目 (招募角色、連結佔位) 用全形 `。` 起頭,前面兩個空格。
- 事件之間用只有線條的空行分隔。

### 線條字元

**只使用 `┬`、`│`、`┴` 三種**,不用交會字元。
- `┬` 開始、`┴` 結束、`│` 持續中 (開始與結束之間每一行都要有,不可斷線)。
- 每個項目群佔自己的一欄 (固定水平位置),欄之間留一個空格。

### 欄位規劃

1. 先列出所有項目的起訖日,再決定欄數。
2. **結束日相同的項目併成一欄** (例:活動 + 特選招募;同日結束即可,時刻不同也沒關係,如 09:59 與 02:59)。
3. 結束日不同的項目,即使同日開始也要拆欄,否則 `┴` 會落錯列。
4. **同欄接力**:A 結束、B 緊接開始 (時間不重疊) 時,B 沿用 A 的同一欄。A 的 `┴` 放在 B 那一列的**上一列**(不寫日期),B 那列寫日期並以 `┬` 起頭:
   ```
   `     │ │`  。
   `     │ ┴`
   `7/15 │ ┬` - 大決戰「HOD」屋內戰
   `     │ │`  。
   `7/22 ┴ ┴`
   ```
5. 某欄全部結束後又有新項目,可在下一列重新 `┬` 起一段;超出時間範圍的新項目直接 `┴` 收尾。
6. 長期項目 (制約解除決戰約四週) 通常放最左欄,橫跨整段。

### 日期欄寬度

日期欄寬度以最長日期為準,**所有列統一寬度**。出現 `10/13`、`11/10` 這類五字元日期時,整份加寬一格,線條才不會黏住日期:

```
`9/23    ┬  ` - 活動開始
`9/24  ┬ │  ` - 制約解除決戰「TIPHARETH」重裝甲
`10/7  │ ┴ ┴`
`10/28 ┴    `
```

### 結束日不重複標註

時間軸左側已經有該結束日期的刻度時,**不要再寫 `。~ 9/9(三) 10:59`**。只有結束日不在任何刻度上、又不值得多開一列時,才用 `。~ 日期` 補充。

### 連結佔位

戰鬥類內容 (制約解除決戰、總力戰、大決戰、合同火力演習、綜合戰術考試) 事件下方放一行 `。` 作為 Discord 頻道連結佔位;有連結就寫 `。https://discord.com/channels/...`,沒有就留空並告知待補。

## 常見項目寫法

- **國際版募集**:特選招募、特別特選招募、安可招募、PremiumDash招募。
- **日版募集**:pick-up募集、Recollect募集、Limited Dash募集。
- **戰鬥**:`類別「BOSS英文名」地形/裝甲`,例:`制約解除決戰「TIPHARETH」彈力裝甲`、`總力戰「GOZ」野戰`。
  - 地形照來源:國際版 野戰/城鎮戰/室內戰;日版 屋外戦→野戰、市街地戦→城鎮戰、屋内戦→屋內戰。
- **合同火力演習 / 綜合戰術考試**:寫考試種類,例:`合同火力演習「護衛演習」開始`、`綜合戰術考試「射擊考試」城鎮戰`。
- **活動**:活動、復刻活動、迷你活動、特別活動、官網活動、WebView活動。復刻的標「復刻活動」。
- **戰術大賽新賽季** (日版稱戰術對抗戰):不畫進時間軸,在 `### 日程` 標題下、時間軸之前列成條列,下一行縮排放討論串連結。國際版寫「戰術大賽賽季N開始」,日版寫「戰術對抗戰賽季N開始」。
  ```
  - 戰術大賽賽季11開始
    - (討論串連結)
  ```

### 圖示標記

角色名後用 emoji 短代碼,**不用 `<:name:數字ID>`**:
- `:icon_revival:` 復刻 (公告標「[復刻]」或「復刻ピックアップ」)
- `:icon_limited:` 限定 (公告寫明往後不列入 pick-up/通常募集,如「期間限定」、特別特選招募、Recollect 對象)

兩個都有時順序為 `:icon_limited: :icon_revival:`,角色名與代碼間空一格,行末保留一個空格。新角色、非限定非復刻的不標。

```
`     │  `  。沙織(泳裝) :icon_limited: :icon_revival: 
`     │  `  。季(兔女郎) :icon_revival: 
`     │  `  。朱音(制服)
```

## 預告主視覺圖

預告貼文最後附上一張公告中的主視覺圖,依優先順序挑一張:
1. 主線劇情更新的視覺圖
2. 新活動的主視覺圖
3. 復刻活動的主視覺圖
4. 其他當期最主要內容的視覺圖 (例:總結算)

不選學生介紹、招募、商品、組合包、玩法說明等圖片。

## 討論串命名

戰鬥類內容 (總力戰、大決戰、制約解除決戰、合同火力演習、綜合戰術考試) 會在論壇各開一個討論串。標題格式:

- 總力戰、大決戰、制約解除決戰:`{版本}第{期數}期{類別} - {副標}`
  - 例:`國際版第86期總力戰 - 室內GREGORIUS`、`日版第38期大決戰 - 屋外GEBURAH`、`國際版第28期制約解除決戰 - 彈力裝甲TIPHARETH`
- 合同火力演習 (日版)、綜合戰術考試 (國際版):`{版本}{類別} - 第{次數}次{副標}`
  - 例:`日版合同火力演習 - 第9次護衛演習`、`國際版綜合戰術考試 - 第15次射擊考試`
- 戰術大賽 (戰術對抗戰) 新賽季:國際版 `國際版第{賽季}賽季 {地形}{區}區`、日版 `日版第{賽季}賽季 {地形}第{區}區域`
  - 例:`國際版第11賽季 野外4區`、`日版第11賽季 屋外第4區域`
  - 地形:國際版 `野外`/`城鎮`/`室內`;日版 `屋外`/`市街地`/`屋内`。
  - 區是依地形輪替:同地形上一次是 3 區,這次就是 4 區。
- 類別一律用中文:總力戰、大決戰、制約解除決戰、合同火力演習、綜合戰術考試。

副標寫法:
- 總力戰、大決戰:地形 + BOSS 英文大寫,中間不空格;多個 BOSS 以空格分隔。
  - 國際版地形:室內戰→`室內`、城鎮戰→`城鎮`、野戰→`野戰`。例:`室內GREGORIUS`、`野戰WAKAMO HOVERCRAFT`
  - 日版地形沿用日文、去掉「戦」:屋内戦→`屋内`、市街地戦→`市街地`、屋外戦→`屋外`。例:`市街地DRUMBARKA`
- 制約解除決戰:裝甲類型 (中文) + BOSS 英文大寫。例:`彈力裝甲TIPHARETH`、`特殊裝甲THE FURY OF SET`
- 演習/考試:種類名稱照該伺服器寫法。例:`護衛演習`、`射擊考試`

期數、次數、賽季與區由系統依論壇既有標題自動 +1 (總力戰與大決戰分開計;演習/考試依種類分開計;戰術大賽的區依地形分開計)。
討論串第一則訊息是日期區間 `10/20 - 10/27` (戰術大賽只寫開始 `9/8~`),附上公告中該內容的主視覺圖。

## 翻譯 (中↔日)

- **時間軸線條原樣保留**,不動任何字元、不重新排版。
- **BOSS 英文名、emoji 短代碼不翻譯**。
- 翻譯範圍:標題 (維修預告 ↔ メンテナンス予告)、區塊名 (劇情 ↔ ストーリー、更新 ↔ アップデート、日程 ↔ スケジュール)、事件描述。
- 募集名:pick-up募集 ↔ ピックアップ募集、Recollect募集 ↔ リコレクト募集。
- 活動名換回該伺服器官方原名 (高地人鐵道爆走事件 ↔ ハイランダー鉄道爆走事件)。
- 時區照原稿 (UTC+8),除非使用者要求改。
